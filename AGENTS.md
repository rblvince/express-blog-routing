# Istruzioni del progetto

Questa app è un esercizio Boolean: un server Express con routing CRUD dimostrativo per i post.

L'app non usa un database né dati veri; tutte le risposte sono solo testuali, tranne l'asset statico di prova.

Stack: Node.js, Express 5 e JavaScript CommonJS (`require`).

Regole di stile:
- Usa 2 spazi per l'indentazione.
- Termina le istruzioni con il punto e virgola.
- Mantieni i router separati nella cartella `routers/`.
